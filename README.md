# 📱 bleed_phone

**A modern, Prodigy 4.0-inspired phone system for FiveM.**

---

## 📖 Overview

**bleed_phone** is a custom-developed FiveM phone resource inspired by the design, functionality, and user experience of **Prodigy Roleplay 4.0**.

The project aims to deliver a premium, immersive, and feature-rich mobile phone experience for FiveM roleplay servers, combining modern interface design with responsive interactions and extensive in-game functionality.

Built with performance, usability, and customisation in mind, bleed_phone is intended to provide a polished alternative to traditional FiveM phone resources.

> ⚠️ **IMPORTANT: ACTIVE DEVELOPMENT**
>
> bleed_phone is currently a work in progress and is **not production-ready**. Certain applications, features, and integrations may be incomplete, unavailable, or subject to change.
>
> This repository is primarily intended for development, testing, and tracking project progress.

## 📦 Installation

> Installation instructions are provisional and may change as development progresses.

1. Download or clone this repository.
2. Place the resource inside your FiveM server's `resources` directory.
3. Ensure the resource folder is named `bleed_phone`.
4. Install any required dependencies and database files documented for your version.
5. Add the following to your `server.cfg`:

```cfg
ensure bleed_phone
```

6. Restart your FiveM server and review the console for errors.

**Note:** A complete installation guide, including verified dependencies and configuration requirements, will be provided when the resource reaches a usable release.
